# Compact A4 구성

## LDS 공식 토큰과 매뉴얼 선택의 구분

Core/Theme가 색·폰트·타입·간격·곡률 값을 소유한다. 다음 표의 역할 배정과 A4 지오메트리는
**Manual compact 프리셋**의 선택이다. Core의 값을 바꾸거나 다른 제품에 강제하지 않는다.

| 역할 | 매핑 |
|---|---|
| 표지 제목 | title2, ExtraBold |
| 섹션 제목 바 | headline1, Bold, radius-8 |
| 단계 제목·번호 | headline2, 17px / 24px / 600 |
| 본문·표 | label1 reading, 14px / 22px |
| 메타·보조 안내 | label2 reading, 13px / 20px |
| 캡션·페이지 번호 | caption1, 12px / 16px |
| 콜아웃 | 실제 Core Callout, compact, 제목 필수; 내부 스타일 변경 금지 |
| 문서 표 외곽 / 화면 모서리 | radius-8 / radius-xs |

페이지는 A4 210×297mm, 좌우·위 여백 13mm, 하단 콘텐츠 예약 20mm다.
페이지 번호는 아래 9mm에 위치하며 콘텐츠와 겹치지 않는다.

## 간격은 관계로 결정

| 관계 | LDS 토큰 |
|---|---|
| 제목 바 → 도입 문장 | space-4 (16px) |
| 단계 제목 → 설명 | space-1 (4px) |
| 설명 → 해당 화면 | space-3 (12px) |
| 화면 → 캡션 | space-2 (8px) |
| 한 단계 끝 → 다음 단계 | space-6 (24px) |
| 본문 → 콜아웃 | space-4 (16px) |

steps는 순서 목록으로 구성하며 번호와 제목은 같은 타입 역할을 쓴다.
Callout은 상시 안내, help는 현재 단계에 종속되는 짧은 도움말이다.
제목 없는 긴 Callout, 고립된 보조 제목, 페이지마다 다른 캡션 크기를 만들지 않는다.

## 화면과 분량

로고는 공식 LDS Theme 자산을 원래 비율·35mm 폭으로 표지 제목 위에 둔다. 문서 정보는 한 줄에 두 항목을 배치하고, 주소 등 주요 값은 labeled list의 emphasis로 강조한다.

한 장의 화면은 본문 폭 또는 reading(170mm), 두 장은 compact(151mm) 폭을 기본으로 한다. 세로 화면은 columns를
사용할 수 있다. 레이아웃은 내용에 맞춰 선택하며 모든 페이지를 같은 도식으로 채우지 않는다.
스크린샷 자체의 버튼 글자가 읽히지 않으면 확대 상세를 추가하거나 페이지를 나눈다.
본문 font-size를 낮추거나 변형 scale로 전체 페이지를 몰래 축소하지 않는다.
A4 미리보기의 가로 스크롤은 의도된 매체 동작이며 반응형 앱이라고 설명하지 않는다.
